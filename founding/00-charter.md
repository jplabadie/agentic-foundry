# Charter

Foundry is a project template for teams that include coding agents.

The product of this repository is the contract those agents have to pass. It is not a harness and not an application. Copy it, rename it, and put the real system beside the same founding set.

A document in `founding/` that the checks do not execute is a wish. The manifest, the invariants, the rubric, and the workflow are executed by `scripts/bedrock.mjs` on every pull request.
